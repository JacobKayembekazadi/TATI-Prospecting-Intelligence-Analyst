## What it does

Feed it a company name. Get back a full intelligence brief in seconds:

- 🔍 **Research** — company overview, recent news, tech stack, org signals
- 📊 **Scoring** — fit score based on size, budget indicators, and urgency signals  
- 📋 **Brief** — structured 1-page prospect summary
- 💬 **Outreach angle** — recommended hook and best contact to target

---

## Built for

SDRs, founders, and consultants who need to qualify and prioritize leads fast — without a research team or hours of manual digging.

## Local setup

```bash

cd TATI-Prospecting-Intelligence-Analyst
npm install
# Add GEMINI_API_KEY to .env
npm run dev
```
